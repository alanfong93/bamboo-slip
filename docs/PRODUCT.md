# Who

A software or AI builder who already has notes, articles, transcripts, or code, and wants an assistant to use that material at the point of work.

The kit is named **bamboo-slip** (简牍): keep the original slip; compile only as a pointer back.

# Must be able to

1. Drop a trusted source into `raw/` and keep it verbatim
2. Compile a cited wiki note from those sources
3. Re-index MemPalace after any vault write
4. Ask an assistant for help with one trusted source in the prompt, and require the answer to point back to it

# Done when

Someone can clone this kit, add one source, compile one wiki note, index it, and get an answer that cites the source — without copying anyone else's vault.

# Not this project

A personal vault dump. A live file watcher. PARA or Zettelkasten as the required method. Hermes or OpenClaw support. A claim that compiled notes are verified.
